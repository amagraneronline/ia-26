Instalación en 5 pasos

  1. Descarga el archivo .jsUtiliza el botón superior. No necesitas un ZIP.
  2. Abre TurboWarpEntra en el editor desde el navegador.
  3. Añade una extensión personalizadaSelecciona Custom Extension → File.
  4. Cárgala sin sandboxElige el archivo .js y activa «Run extension without sandbox».
  5. Importa tu JSONPulsa el bloque «cargar modelo JSON de gestos» y después activa la cámara.
Abrir TurboWarp ↗

¿Qué archivo necesito?

.js → instala los bloques y el motor de reconocimiento en TurboWarp.

.json → contiene tus clases y ejemplos. Se descarga desde el entrenador.

Ir al entrenador ↗

Si algo no funciona

No aparece «Gestos entrenados»

Revisa que cargaste el archivo .js, y no el PDF o el JSON, y que marcaste la ejecución sin sandbox.

No se abre el selector JSON

Pulsa directamente el bloque de carga desde la paleta de TurboWarp. El navegador puede bloquearlo si se invoca sin interacción del usuario.

La cámara no se activa

Permite la webcam en el navegador, comprueba que la página usa HTTPS y espera a que se descarguen las bibliotecas.

Permisos de seguridad

La extensión necesita ejecutarse sin sandbox para utilizar la webcam. Este modo da permisos amplios: utiliza solo la extensión del proyecto que haya revisado el profesorado. Documentación oficial ↗
