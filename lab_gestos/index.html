Dos fases, un proyecto

Del aprendizaje automático al videojuego

Cada pareja crea su propio reconocedor y luego programa el comportamiento del juego con bloques. No necesita escribir Python ni JavaScript.

◉
Fase 01 · Entrenamiento

Entrenador de gestos

Utiliza la cámara y los 21 puntos de la mano para capturar ejemplos. Tú decides qué gestos aprenderá el clasificador.

  • Comienza sin clases predeterminadas
  • Añade y renombra las clases libremente
  • Captura ejemplos y valida las predicciones
  • Descarga tu aprendizaje como archivo JSON
Abrir el entrenador →
▦
Fase 02 · Programación

TurboWarp y extensión

Descarga nuestra extensión JavaScript, impórtala en TurboWarp y carga el JSON creado en la fase anterior.

  • Extensión descargable en formato .js
  • Guía PDF visible en la propia web
  • Bloques de reconocimiento de gestos
  • Programación con variables, eventos y condicionales
Descargar extensión y ver guía →

Antes de empezar: utiliza Chrome o Edge, permite el acceso a la webcam y abre el entrenador desde HTTPS o localhost. Para utilizar ml5.js es necesaria una conexión a Internet que permita descargar sus bibliotecas y el modelo HandPose.
