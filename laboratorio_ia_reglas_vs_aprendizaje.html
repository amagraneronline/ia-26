Laboratorio IA: ¿Reglas o aprendizaje?

Experimento interactivo para comprender la diferencia entre el software tradicional y el aprendizaje automático.

¿Qué vamos a descubrir?

Dos sistemas pueden intentar resolver el mismo problema de maneras muy diferentes. En este laboratorio vamos a utilizar un ejemplo sencillo: detectar mensajes SPAM.

💻 Software tradicional

Una persona escribe las reglas que el programa debe seguir.

Datos + reglas → resultado

🧠 Aprendizaje automático

El sistema recibe ejemplos y aprende patrones durante el entrenamiento.

Datos + ejemplos → modelo → predicción

🔄 Mejora del modelo

El modelo no mejora simplemente con el tiempo: necesita nuevos datos y un nuevo entrenamiento.

Nuevos datos + reentrenamiento

Instrucciones

  1. Pulsa Siguiente mensaje.
  2. Decide primero tú si el mensaje es SPAM o NO SPAM.
  3. Observa la respuesta del sistema tradicional y del sistema de aprendizaje automático.
  4. Cuando aparezcan casos nuevos, modifica ambos sistemas.
  5. Compara qué necesita cada uno para mejorar.

🧩 ¿Qué acabamos de observar?

💻 Software tradicional

Para reconocer un caso nuevo, una persona debe modificar las reglas de forma explícita.

🧠 Machine Learning

El comportamiento puede cambiar cuando se incorporan nuevos ejemplos y el modelo se vuelve a entrenar.

⚠️ Importante

Un modelo no aprende necesariamente mientras lo usamos. Aprender requiere datos, entrenamiento y evaluación.
